A single museum label for the year 3000, written for make.fun's "Museum of the Year 3000" bounty. The program holds one original line — the label a future curator puts beside a television remote control, misread as a sacred wand — checks that it is a single line of 1 to 200 characters, and writes it to the output file. It uses only the Node standard library and is fully deterministic: the same label comes out on every run.

## Run it

```sh
node main.ts
```
